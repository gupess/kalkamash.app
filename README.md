# تطبيق بوابة الطلبة (أندرويد)

1. أنشئ مستودعاً **خاصاً (Private)** جديداً على GitHub، مثلاً: kalkamash-app
2. ارفع كل محتويات هذا المجلد (مع المجلد المخفي .github والملف app/release.jks).
3. افتح تبويب **Actions** ← **Build APK** ← **Run workflow**، وانتظر 5 إلى 10 دقائق.
4. من صفحة التشغيل نزّل **kalkamash-app** من قسم Artifacts، وفك الضغط، وفيه app-release.apk.
5. شارك الملف وثبّته (اسمح بالتثبيت من مصدر غير معروف).

التطبيق يفتح الموقع https://gupess.github.io/Site/ ، فأي تحديث للموقع يصل تلقائياً بدون إعادة بناء.
احتفظ بنسخة من app/release.jks : نفس المفتاح مطلوب لتحديث التطبيق فوق النسخة المثبتة.
